# Caplany Demo v1
Buyer-facing functional demo for Caplany Pool Services.

## Run
`npm start`

## Test
`npm test`

## Scope
Two deterministic intake paths (fault and maintenance), conditional fields, contact details, safe demo photo handling, availability preference, review, submission, structured Caplany result. No AI diagnosis, pricing, booking, CRM, WhatsApp, or production Caplany integration.
